# Video Converter

[English](README.en.md) | **Русский**

![Screenshot](images/screenshot.png)

## Описание

Простая программа для быстрого перекодирования видеофайлов в формат MP4 с использованием аппаратного ускорителя видеокарт NVIDIA (NVENC). Основана на [FFmpeg](https://ffmpeg.org/).

Приложение рассчитано на пакетную работу: список файлов, общие настройки кодирования на панели управления и, при необходимости, индивидуальные настройки для отдельных строк. Всё нужное (`ffmpeg.exe`, `ffprobe.exe`, `mpv.exe`) поставляется вместе с программой — устанавливать что-либо дополнительно не нужно.

## Возможности

- **Пакетная конвертация** очереди файлов с общим и построчным прогрессом.
- **Аппаратное кодирование NVENC** (`h264_nvenc`, preset `p4`, profile `high`, `spatial_aq`). Если NVENC недоступен, автоматически используется программный кодек `libx264` — медленнее, но результат тот же формат.
- **Два режима качества:** постоянное качество (QP/CRF, диапазон 14–30) и постоянный битрейт (CBR).
- **Прогноз размера выходного файла** до запуска конвертации — столбец «Ожид. размер».
- **HDR → SDR тонмаппинг** (`zscale` + `tonemap=hable`) в режимах «Авто», «Вкл», «Выкл».
- **Ограничение разрешения до Full HD** (1920×1080) с сохранением пропорций.
- **Выбор аудиодорожки** для каждого файла; перекодирование в AAC с битрейтом по числу каналов (моно — 128k, стерео — 192k, 5.1 — 384k, 7.1 — 512k).
- **Сохранение субтитров** в MP4 (`mov_text`) с переносом языка и названия дорожки.
- **Режимы «не конвертировать»** отдельно для видео и аудио (потоковое копирование, `-c:v copy` / `-c:a copy`).
- **Копирование тегов** из исходного MP4 в результат (через `mutagen`).
- **Предпросмотр** исходного и сконвертированного файла во встроенном mpv с выбранной аудиодорожкой.
- **Drag & drop**, сортировка списка по клику на заголовок столбца, контекстное меню, лог FFmpeg с режимом Debug.
- **Поддержка HiDPI**, звуковой сигнал по завершении очереди.

Входные форматы: MKV, MP4, MOV, AVI. Выходной формат: MP4 (H.264 + AAC).

## Установка

Скачайте установщик `Video_Converter <версия> Setup.exe` из раздела [Releases](https://github.com/Fan4Metal/video_converter/releases) и запустите его. Программа ставится в профиль пользователя (`%APPDATA%\video_converter`) и не требует прав администратора.

Требования: Windows 10/11 x64. Для аппаратного ускорения — видеокарта NVIDIA с поддержкой NVENC и актуальный драйвер; без неё программа работает на CPU.

## Использование

1. Добавьте файлы кнопкой **«Добавить файлы...»** или перетащите их в окно.
2. При необходимости укажите папку назначения (**«Выбрать папку...»**). Если папка не задана, файлы сохраняются рядом с исходными. Путь запоминается между запусками.
3. Кнопка-переключатель **`_conv`** управляет добавлением суффикса к имени выходного файла. Если файл с таким именем уже существует, к имени добавляется номер.
4. Выберите режим кодирования и качество, отметьте нужные опции.
5. Нажмите **«▶ Начать конвертацию»**. Во время работы кнопка превращается в **«⏹ Отмена»**.

### Настройки кодирования

| Настройка | Описание |
| --- | --- |
| 🎯 Постоянное качество (QP) | Слайдер задаёт QP для NVENC (или CRF для libx264). Меньше значение — лучше качество и больше файл. Разумный диапазон: 18–28. |
| 📦 Постоянный битрейт (CBR) | Слайдер задаёт битрейт видео в Мбит/с. Подходит, когда нужен предсказуемый размер. |
| Ограничивать разрешение до FullHD | Кадры больше 1920×1080 уменьшаются с сохранением пропорций. |
| HDR→SDR | «Авто» — тонмаппинг включается, если ffprobe определил HDR (PQ/HLG); «Вкл»/«Выкл» — принудительно. |
| не конв. видео | Видеопоток копируется без перекодирования. |
| не конв. аудио | Аудиопоток копируется без перекодирования. |
| копировать теги | Переносит теги из исходного MP4 в результат. Глобальная настройка. |
| сохранить субтитры | Показывает столбец субтитров и записывает отмеченные текстовые дорожки в MP4. |
| Debug | Выводит в лог сырой вывод FFmpeg. |

### Общие и индивидуальные настройки

Настройки на панели управления по умолчанию применяются ко всем файлам — в столбце «Параметры» такие строки помечены как **⚙️Глобальные**.

Если выделить одну или несколько строк и изменить настройки, они сохранятся именно для этих строк (строка подсвечивается, в «Параметрах» появляется описание вида `QP=22, fullHD, TM=auto`). Через контекстное меню такие настройки можно **применить ко всем остальным файлам** или **сбросить к глобальным**.

### Столбцы списка

`Файл` · `Разрешение` · `Битрейт` · `Размер` · `Ожид. размер` · `Длительность` · `Аудио дорожка` · `Субтитры` · `Параметры` · `Статус` · `Прогресс`

Клик по заголовку сортирует список, повторный клик меняет направление. Столбец «Субтитры» появляется только при включённой опции «сохранить субтитры».

**Ожидаемый размер** считается заранее: `≈` — точный расчёт (CBR или копирование потока), `~` — приблизительная оценка для режима QP (модель «бит на пиксель», ограниченная битрейтом источника). Во время кодирования оценка уточняется по реальным данным FFmpeg, а по завершении столбец показывает фактический размер файла.

### Управление списком

- **Двойной клик** — предпросмотр файла в mpv с выбранной аудиодорожкой.
- **Delete** — удалить выделенные строки.
- **Правый клик** — контекстное меню: воспроизвести исходный или сконвертированный файл, применить настройки к другим файлам, сбросить настройки конвертации, открыть папку с файлом или папку вывода, удалить из списка, очистить список.

## Сборка из исходников

Проект использует [uv](https://docs.astral.sh/uv/) и требует Python 3.14+.

```bash
git clone https://github.com/Fan4Metal/video_converter
cd video_converter
uv sync            # зависимости приложения + dev-группа (PyInstaller)
uv run main.py     # запуск из исходников
```

### Внешние бинарники

`ffmpeg.exe`, `ffprobe.exe` и `mpv.exe` **не входят в репозиторий** — их нужно скачать отдельно и положить рядом с `main.py`:

- [FFmpeg для Windows](https://ffmpeg.org/download.html#build-windows) — `ffmpeg.exe` и `ffprobe.exe`;
- [mpv для Windows](https://mpv.io/installation/) — `mpv.exe`.

Без них программа не запустится из исходников, а `make_release.py` не соберёт установщик: PyInstaller включает эти файлы в сборку через `--add-data`, и оттуда они попадают в установщик Inno Setup. Аналогично собираются `LICENSE`, `sound.wav` и иконки.

Лицензии всех включённых в сборку компонентов перечислены в файле [LICENSE](LICENSE) — он показывается в установщике и в окне «О программе».

### Сборка релиза

Помимо зависимостей проекта понадобится установленный [Inno Setup 6](https://jrsoftware.org/isdl.php) — им собирается установщик. Скрипт ищет компилятор `ISCC.exe` в стандартных путях (`C:\Program Files (x86)\Inno Setup 6` и `C:\Program Files\Inno Setup 6`), а если не находит — пробует вызвать его через `PATH`.

```bash
uv run make_release.py
```

Скрипт берёт версию из `__VERSION__` в `main.py`, собирает `dist\VC` в режиме `--onedir` через PyInstaller, копирует русскую локализацию wxPython, подставляет версию в `setup.iss` и вызывает `ISCC.exe`. Готовый установщик появится в `dist`.

Если сборочные инструменты не нужны, зависимости можно поставить без них:

```bash
uv sync --no-dev
```

## Технические детали

- Видео: `h264_nvenc` (VBR с `-cq` для QP, либо `-b:v`/`-maxrate`/`-bufsize` для CBR), фолбэк на `libx264` (`-crf` / CBR, preset `medium`).
- Пиксельный формат выхода — `yuv420p`; при тонмаппинге используется цепочка `zscale=t=linear:npl=30 → tonemap=hable:param=1.5 → zscale=t=bt709:m=bt709`.
- Аудио: `aac` с числом каналов исходной дорожки и битрейтом по таблице выше.
- Из результата удаляются метаданные контейнера (`-map_metadata -1`) и скрытые субтитры EIA-608/CEA-608 (`-bsf:v filter_units=remove_types=6`).
- Информация о файлах собирается одним вызовом `ffprobe` при добавлении и кэшируется.
- Путь к папке сохранения хранится в реестре: `HKEY_CURRENT_USER\SOFTWARE\video_converter`.
